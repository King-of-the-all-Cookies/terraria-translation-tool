# テラリア翻訳ツール

テラリア翻訳ツールは、ゲーム「テラリア」のローカライゼーションファイルの翻訳と管理を容易にするためのデスクトップアプリケーションです。このツールを使用すると、ユーザーはユーザーフレンドリーなインターフェースでローカライゼーションファイルを開いたり、編集したり、保存したりできます。

## 機能

- **ローカライゼーションファイルの開閉**: `.txt`形式のローカライゼーションファイルを簡単に開いて解析します。
- **グループ表示**: タグごとにグループ化された翻訳を表示および編集します。
- **翻訳の編集**: アプリケーション内で直接翻訳を変更します。
- **変更の保存**: 変更内容をローカライゼーションファイルに保存します。

## はじめに

### 前提条件

- Python 3.x
- PyQt6ライブラリ

### インストール

1. リポジトリをクローンします:
   ```bash
   git clone https://github.com/King-of-the-all-Cookies/terraria-translation-tool
   ```
2. プロジェクトディレクトリに移動します:
   ```bash
   cd terraria-translation-tool
   ```
3. 必要な依存関係をインストールします:
   ```bash
   pip install PyQt6
   ```

### 使用方法

1. アプリケーションを実行します:
   ```bash
   python main.py
   ```
2. 「File」メニューを使用して、ローカライゼーションファイルを開きます。
3. リストからグループを選択して、翻訳を表示および編集します。
4. 変更を加え、「File」メニューを使用してファイルを保存します。
