# Terraria Translation Tool

The Terraria Translation Tool is a desktop application designed to facilitate the translation and management of localization files for the game Terraria. This tool allows users to open, edit, and save localization files in a user-friendly interface.

## Features

- **Open Localization Files**: Easily open and parse localization files in `.txt` format.
- **Grouped View**: View and edit translations grouped by tags.
- **Edit Translations**: Modify translations directly in the application.
- **Save Changes**: Save your changes back to the localization file.

## Getting Started

### Prerequisites

- Python 3.x
- PyQt6 library

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/King-of-the-all-Cookies/terraria-translation-tool
   ```
2. Navigate to the project directory:
   ```bash
   cd terraria-translation-tool
   ```
3. Install the required dependencies:
   ```bash
   pip install PyQt6
   ```

### Usage

1. Run the application:
   ```bash
   python main.py
   ```
2. Use the "File" menu to open a localization file.
3. Select a group from the list to view and edit translations.
4. Make your changes and save the file using the "File" menu.
