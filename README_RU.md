# Инструмент перевода Terraria

Инструмент перевода Terraria — это настольное приложение, предназначенное для упрощения перевода и управления файлами локализации для игры Terraria. Этот инструмент позволяет пользователям открывать, редактировать и сохранять файлы локализации в удобном интерфейсе.

## Возможности

- **Открытие файлов локализации**: Легко открывайте и анализируйте файлы локализации в формате `.txt`.
- **Групповой просмотр**: Просматривайте и редактируйте переводы, сгруппированные по тегам.
- **Редактирование переводов**: Изменяйте переводы непосредственно в приложении.
- **Сохранение изменений**: Сохраняйте изменения обратно в файл локализации.

## Начало работы

### Предварительные требования

- Python 3.x
- Библиотека PyQt6

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/King-of-the-all-Cookies/terraria-translation-tool
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd terraria-translation-tool
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install PyQt6
   ```

### Использование

1. Запустите приложение:
   ```bash
   python main.py
   ```
2. Используйте меню "File", чтобы открыть файл локализации.
3. Выберите группу из списка, чтобы просмотреть и отредактировать переводы.
4. Внесите изменения и сохраните файл, используя меню "File".
